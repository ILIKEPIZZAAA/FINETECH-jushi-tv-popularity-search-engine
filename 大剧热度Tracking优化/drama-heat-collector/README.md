# drama-heat-collector

开源电视剧热度/榜单采集服务（本地 `localhost` HTTP）。为你投放复盘时自查各平台公开热度，不含任何平台商业数据本体、不需要任何平台账号或 cookie。

```bash
npm install
npm start          # 默认 http://127.0.0.1:8890
```

> 浏览器型源（猫眼）需要本机装有 **Chrome/Chromium**——采集服务用无头系统 Chrome 打开官网大屏并读取页面自己拉回的数据，所以无需登录、无需破解、人人可跑。只想要 HTTP 直连源时设 `DISABLE_BROWSER=1`。

## 怎么用

```bash
curl 'http://127.0.0.1:8890/collect/all?title=交锋'
curl 'http://127.0.0.1:8890/collect/guduo?title=早春晴朗'
curl 'http://127.0.0.1:8890/collect/maoyan?title=早春晴朗'
curl 'http://127.0.0.1:8890/ratings/collect?title=伪装者'
curl 'http://127.0.0.1:8890/ping'
```

返回统一结构：

```jsonc
{
  "ok": true,
  "label": "maoyan",
  "data": {
    "platform": "maoyan",   // guduo | maoyan | tencent | iqiyi ...
    "title": "交锋",
    "date": "2026-09-08",   // 上海自然日；骨朵为 T+1（次日发布）时回退到最近完整日的榜
    "heat": 6114.22,
    "rank": 1,
    "sourceUrl": "…",
    "fetchedAt": "ISO 时间"
  }
}
```

「抓取今日」的语义：**实时源取当下**，T+1 源（骨朵）自动回落到最近一个完整自然日。这是数据来源自身的发布节奏，不是 bug。

## 已接入 & 路线

| 源（平台） | 采集方式 | 认证 | 状态 |
|---|---|---|---|
| 骨朵（骨朵数据） | HTTP 直连公开榜单接口 | 无 | ✅ |
| 猫眼（实时热度大屏） | Playwright 无头 Chrome 读官方大屏自己拉回的 XHR | 无 | ✅ |
| 台端收视率 | 公开逐日收视表，按卫视/日期/时段拆行 | 无 | ✅（覆盖取决于公开表） |
| 其他长视频平台前台值 | 不单独采集，统一通过猫眼看板 | — | 由上层项目按猫眼口径入库 |
| 云合 / 微博 | 需合规账号或导出适配器 | 视账号而定 | ⏳ |

架构是**两层采集器**，新平台按需挂到 `/collect/*` 即可：
1. **HTTP 直连型**（骨朵这类开放接口）：照 `guduo.js` 的样板。
2. **浏览器型**（猫眼这类带风控/渲染的）：照 `maoyan.js` 用一次系统 Chrome，监听页面自己发出的 XHR，别去逆向签名。

## 现状与边界（诚实声明）

- 大屏当前只读默认「电视剧+网络剧」分类。目标剧若在别的分类、或当天已不在热榜，会返回 `ok:false` 并提示可换分类或人工存档。
- 猫眼是美团系风控最强的产品：频繁采集可能弹人机。所以单剧一天理想只采 1 次；本服务不做你已知的强缓存（交由上层 UI 决策）。
- 浏览器型源首次请求会启动系统 Chrome（约 2–5s），之后常驻复用，单次请求几百毫秒到几秒。
